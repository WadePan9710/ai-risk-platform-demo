# AI 风控策略驾驶舱（Demo）

> 面向小周期现金贷「老客策略 × 老客模型」负责人的决策驾驶舱。
> 本仓库为脱敏 demo：零真实数据、零外部依赖（Node ≥18 内置模块即可运行）、内置合成数据生成器。

## 为什么做这个

作为风控策略团队负责人，每天要回答三个问题：
1. **今天产品跑得怎么样**（放款/通过率/分层占比）？
2. **我的策略还在起效吗**（EG/CG 分子分母、功效检验、规则精准度）？
3. **模型还能用吗**（多模型 AUC 体检、新鲜度）？

这个驾驶舱把三件事压成一屏，每张卡标注 数据来源/刷新频率/读不到时的显示。

## 核心设计决策

| 决策 | 为什么 | 实现 |
|---|---|---|
| **首逾期主线**（T+1 可判） | 7 天产品到期次日即可判首逾，比 dpd7 早 6 天看到风险；soft7/dpd7 降为成熟对照 | `server/kpi/ab.js` |
| **soft7/dpd7 仅成熟对照** | 展期会把 bad7 回溯洗好 → 趋势只看 soft7；dpd7 不含展期仅作参考 | 卡2/卡3 注释 + 对照列 |
| **整周可比门控** | 未满 T+1 的周参与环比会出假信号（成熟 26% 的周首逾 10.7% vs 上周 45.2%，不可比） | `weekOverWeek()` foComparable 门控 |
| **EG-only 策略有效性** | 0831 提交版规则只对 EG 生效；CG 跑旧策略没有一致率概念 | monitorHourly egValid 切片 |
| **分子分母同时下发** | 100% = 1/1 毫无意义；页面渲染 `率% (坏/可判n)` | abTierTable Due1/FONum/Due7/Bad7Num |
| **两比例 z 功效门槛** | min n≥10 才可检验，不可判格显示中性文案 | abPower() twoPropZ + Wilson |
| **fail-loudly 数据源校验** | 字段缺失 → `数据源未就绪：<字段>` 显式上报，禁止默认值兜底 | latestModelHealth() 校验逻辑 |
| **规则质量周报** | 命中多 ≠ 精准（E 档规则命中 35 决策首逾仅 2.9% = 陪跑）；每周 Top2 规则逾期率追踪 | ruleQualityWeekly() |

## 架构

```
┌──────────────────────────────────────────────┐
│                驾驶舱前端 (vanilla JS)         │
│  六卡布局 · 无框架依赖 · fetch JSON API         │
└──────────────────────┬───────────────────────┘
                       │ /api/kpi (JSON)
┌──────────────────────▼───────────────────────┐
│           KPI 复算层（纯函数）                  │
│  dueWeekSeries · weekOverWeek · abTierTable    │
│  abPower(两比例z+Wilson) · conclusions         │
├──────────────────────────────────────────────┤
│           数据适配层（可替换）                   │
│  demo: mock/generator.js（种子合成数据）         │
│  生产: MySQL 只读（risk_source_th）+ 跑批产物    │
└──────────────────────────────────────────────┘
```

生产版在此基础上增加：
- **risk-agent**（风控AI日报 + 规则引擎 + LLM 解读 + 处置闭环 + 模型体检 + 决策联动名单）
- **sms-review**（BGE-M3 推理 + 百度翻译 + 人工审核 ✓/✗ 闭环）
- **watchdog**（5 分钟自动探活 + 拉起）
- **AI 归纳入库**（dsh Agent 读文章 → 结构化知识文档）

## 快速开始

```bash
node server/server.js
# → http://localhost:3000
```

零 npm install（内置模块）、零配置、零真实数据。合成数据由种子生成，刷新页面数据不变。

## 口径速查

| 口径 | 定义 | 用途 |
|---|---|---|
| 首逾期 | 到期≥1天未结清 | **主线**（T+1 可判，数据最新） |
| dpd7 | 到期≥7天仍未结清 | 成熟对照（样本稳定但滞后） |
| soft7 | dpd7 ∪ 付费展期 | 趋势参考（展期回溯不洗 soft7） |
| 首逾期周环比 | 整周到期才可比 | 未满 T+1 的周标"观察中"不参与 |

```
docs/
  metrics.md         # 口径决策与告警阈值
  fail-loudly.md     # fail-loudly 契约模式
```
