# 口径与架构决策（面试叙事稿）

## 背景

泰国小周期（7天）现金贷，老客续贷策略 + 老客风控模型。作为策略 × 模型负责人，需要每天回答：
1. 产品今天跑得怎么样（放款/通过率/分层占比/告警）
2. 策略还在起效吗（EG/CG 分子分母、统计功效、规则精准度）
3. 模型还能用吗（多模型 AUC 体检、新鲜度）

本仓库是生产版的**脱敏架构展示**：零真实数据、零外部服务依赖。

## 三个关键决策

### 1. 逾期率口径分层

发现 dpd7（旧口径）在展期场景下被回溯洗好——"逾期很久最终结清"永远是好。改为三口径分层：
- **首逾期**（T+1）= 主线（数据最新，7天产品次日即可判）
- soft7（含展期）= 趋势参考（展期不洗 soft7）
- dpd7（不含展期）= 成熟对照

### 2. Fail-Loudly 数据源契约

模型体检 AUC=0.494 接近随机被"样本不足"标签掩盖 3 周。根因 = 缺字段时静默兜底填默认值。改造为：
- 契约文档逐字段登记依赖
- 缺任一字段 → 页面显式渲染"数据源未就绪：<字段>"
- 禁止 try-catch 静默、禁止默认值兜底

### 3. 规则质量周报

降档规则命中多 ≠ 精准。E 档规则命中 35 决策首逾期仅 2.9% = 陪跑（与全量基线持平），C 档 44.2% = 精准。每周 Top2 规则逾期率追踪，命中多但逾期率与基线持平的规则标"陪跑"。

## 架构亮点

- **KPI 复算层纯函数化**：数据注入 → 纯计算 → 结构化输出。生产版连 MySQL，demo 连合成数据，接口契约不变
- **统计功效意识**：分档对比全部走两比例 z + min n 门槛，不做小样本对比
- **AI 模块工程化**：BGE-M3 推理 + 规则后处理 + 百度翻译 + LLM 解读 + 人工审核 ✓/✗ 闭环，生产版含处置工单 + 决策联动名单

## 生产版全量功能（本 demo 仅展示 KPI 复算层）

- 风控AI日报：R1-R8 规则 + 图团伙 + 中介聚集 + 催收前置 → 合并分诊名单 → LLM 解读
- 处置闭环：名单 → 工单登记 → 状态回显 → 次日环比
- 模型体检：11 个模型分 AUC + 新鲜度，衰减/接近随机标红
- 决策联动名单：🔴名单导出 CSV → SQL 同步 → 进件规则引擎实时查询
- 短信打标：BGE-M3 推理 → 系统 vs BGE 对比 → 人工审核 ✓/✗ → 重训数据集
- 定时自动化：07:00 扫描 + 周日体检 + 5 分钟看门狗
