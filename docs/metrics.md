# Metrics and decisions

## Main outcome metric

| Metric | Definition | Why |
|---|---|---|
| 首期 dpd1+ | 首期到期 +1 天时点仍未结清 | 7 天产品 T+1 可判，能比 dpd7 提前看到风险 |
| dpd7 | 首期到期 +7 天仍未结清 | 成熟样本对照 |
| soft7 | dpd7 ∪ 付费展期 | 展期不会洗掉风险 |

## Comparability

- 到期日未满 T+1 的样本不从首逾率分母进入结论。
- 周环比只使用完整到期周。
- 观察中的周仍显示单量，但比率保持 `null`。

## EG / CG

- EG 代表实验策略组。
- CG 代表对照策略组。
- 分档比较同时展示决策量、到期量、坏数、率和 p-value。
- 两组到期样本都 ≥10 才标记“可检验”。

## Rule quality

规则质量比较：

- 命中组：同一基础档，至少一条降档规则命中
- 对照组：同一基础档，未发生降档

判定规则：

- 两组均 ≥10 笔才可判定
- 命中组首逾 ≥ 对照组 1.3 倍：精准
- 两组差 <2pp：陪跑
- 命中组反而更干净：待复核
- 其他情况：待观察

这只是规则区分度，不代表因果。

## Model health

- AUC ≥ `0.60`：正常
- `0.55 ≤ AUC < 0.60`：衰减
- AUC < `0.55`：接近随机
- 样本不足或方向未标定：不出强结论

## Fail-loudly

不允许把缺失字段静默补成 0。Demo 中：

- 不足两个完整周：周环比返回不可用原因
- 分档样本不足：仍展示分子分母，但不标记显著
- 模型 AUC 为空：显示“口径未定”或“样本不足”
